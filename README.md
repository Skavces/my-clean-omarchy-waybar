# My Clean Waybar Config

A minimal and clean Waybar configuration.

## Installation

Installation-command (copy and paste in your terminal):

```bash
git clone https://github.com/Skavces/my-clean-omarchy-waybar.git /tmp/repo && cp -rf /tmp/repo/. ~/.config/waybar && rm -rf /tmp/repo && omarchy-restart-waybar
```
